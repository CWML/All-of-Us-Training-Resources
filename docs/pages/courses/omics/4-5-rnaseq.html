4.5 RNA-seq: Gene Activity in Type 2 Diabetes

Normalize RNA-seq counts, find genes that differ in type 2 diabetes with limma-voom, and check whether rs7903146 changes TCF7L2 activity in blood

Omics series, class 5 of 7 · R (edgeR, limma) · 120 minutes

Open the notebook on GitHub Omics series overview Omics for Beginners

Overview

DNA is the same in every cell and fixed from birth. RNA shows which genes are active, and how much, when a sample was taken. All of Us has measured gene activity (RNA sequencing, RNA-seq) in whole blood for about 9,000 participants. We ask which genes are more or less active in people with type 2 diabetes, then connect back to DNA: does the T allele of rs7903146 change how much TCF7L2 is made in blood?

Why this class matters

RNA-seq is one of the most common omics measurements, and its analysis has a step that’s easy to get wrong without noticing: normalization. The statistics package (limma) doesn’t normalize for you; it will happily give p-values for badly normalized data. This class shows each step, checks it, and ends by linking DNA to RNA with an eQTL.

By the end you’ll be able to

  1. Explain what RNA-seq measures, and counts vs TPM
  2. Use the RNA quality measures, and add RNA quality to the model
  3. Normalize counts (TMM, log-CPM), and check that it worked
  4. Run differential expression with limma-voom, and read a volcano plot
  5. Test whether a variant is linked to a gene’s activity (an eQTL), and look it up in All of Us’s results

Analysis at a glance

❓ Questions Which genes are more or less active in the blood of people with type 2 diabetes? Does rs7903146 change TCF7L2 activity in blood?
🧪 The analysis Counts normalized (TMM) and log-transformed; a linear model per gene with limma-voom, adjusted for age, sex, and RNA quality; then an eQTL test
🎯 Why Raw counts can’t be compared until normalized; expression is a number, so linear models; ~29,000 genes, so an adjusted p-value (FDR)
✅ What we conclude Which genes and processes differ, and whether the variant acts through blood
⚠️ What it can’t tell us Cause vs consequence vs treatment; other tissues; whether cells changed or the mix of cells changed
🔗 Connections The variant from 4.1–4.4; proteins in 4.6; both in 4.7. GWAS + eQTL = colocalization

Key concepts

Counts need normalizing

Problem Example Fixed by
Sequencing depth person A sequenced twice as deeply: every gene has twice the reads counts per million (CPM)
Composition a few hugely active genes “use up” reads, making every other gene look lower TMM (edgeR): assumes most genes don’t change, and scales each person so they line up
Skew a few genes have huge counts the log₂ scale (a step of 1 = twice as much)
Low counts are noisy genes with few reads vary a lot by chance voom: gives each value a weight

All of Us did the processing (aligning reads, counting them per gene), but not the normalization: that’s our job, and limma doesn’t do it.

Whole blood

The RNA comes from blood: a mix of cell types, mostly white blood cells. Much of type 2 diabetes happens in the pancreas, liver, muscle, and fat, which blood doesn’t show. And a difference between groups can come from a change in the mix of cells, not each cell’s activity.

Code walk-through

Filter and normalize

1dge <- DGEList(counts = counts, genes = genes, samples = samples)

2keep_genes <- filterByExpr(dge, group = samples$group)
dge <- dge[keep_genes, , keep.lib.sizes = FALSE]
3dge <- calcNormFactors(dge)

4logcpm <- cpm(dge, log = TRUE)
1
One object holding the counts (genes × people), the gene names, and the sample table.
2
Keep genes with enough reads, in enough people, to analyse (about 29,000 of 78,000).
3
TMM normalization: one factor per person, correcting for composition. The notebook then checks these factors and shows boxplots before and after.
4
Normalized log₂ counts per million, for plots and PCA.

Differential expression

1design <- model.matrix(~ group + age + sex_at_birth + rqs, data = samples)

2v   <- voom(dge, design, plot = TRUE)
3fit <- eBayes(lmFit(v, design))

4results <- topTable(fit, coef = "groupcase", number = Inf)
1
The model for every gene: group (case vs control), adjusted for age, sex, and RNA quality (rqs), a technical covariate.
2
voom turns counts into log values with a weight each, and draws the mean-variance trend (a smooth downward curve is what you want).
3
Fit the model to every gene; eBayes() shares information across genes, which makes each test more reliable.
4
The results for the case-vs-control term, every gene, sorted by p-value.

What we found

Results from our test run in October 2026 (CDR v9), 300 cases and 300 controls.

People with RNA-seq 1,312 cases, 5,538 controls
Cases vs controls older (64 vs 52); RNA quality almost identical (7.7 vs 7.8)
Genes kept 28,902 of 77,814
PCA PC1 split everyone into two clusters: sex, not diabetes
Significant genes a few dozen (adjusted p < 0.05)
Higher in diabetes many neutrophil genes: MMP8, LTF, CRISP3, HP, ANXA3
Lower in diabetes ABCG1 (cholesterol transport), NRCAM (the top gene)
Normalization check medians uneven before, level after TMM; voom trend smooth and downward
Pathways (GO) up in diabetes: immune system process (p ≈ 7 × 10⁻⁶), defense response, TNF production, phagocytosis; few genes per term, so a supporting theme
Neutrophil challenge (369 people with a count) neutrophil genes’ logFC shrank about 20–45% (e.g. MMP8 0.70 → 0.54) but didn’t disappear: the cell mix explains part of the signal
TCF7L2 not different between groups (adjusted p ≈ 0.95)
Our eQTL test no effect of the T allele on TCF7L2 (estimate ≈ −0.01, p ≈ 0.6)
All of Us eQTLs (~9,000 people) TCF7L2’s strongest eQTL is a different variant (chr10:112951996_C_T, slope −0.25); rs7903146’s effect is tiny (slope 0.02, p ≈ 0.004)

💬 Discuss:

  • Are the neutrophil genes higher because each neutrophil changed, or because people with diabetes have more neutrophils (inflammation)? How would you tell? (Adjust for neutrophil counts: the challenge exercise.)
  • rs7903146 is one of the strongest diabetes risk variants, yet it barely touches TCF7L2 in blood. What does that say about tissue? (Its known effects are in the pancreas, where insulin is made.)

Instructor notes

TipInstructor tip: timing and pitfalls
  • Run the setup cell before class: installing limma and edgeR takes 5–10 minutes.
  • Loading the counts reads one large compressed file; use the time for questions or a break.
  • The optional enrichment section installs two more Bioconductor packages (a few minutes the first time).
  • The neutrophil challenge is a good lesson in comparing effect sizes rather than p-values: the genes lost significance partly because only 369 of 600 people had a count. The cell now also refits the main model on the same people, for a fair comparison.

Key takeaways

  • RNA-seq counts reads per gene; normalize (TMM, log-CPM) and check it before testing
  • limma doesn’t normalize; voom adds weights for noisy low counts
  • Adjust for technical factors such as RNA quality
  • Blood RNA can reflect a change in the cell mix
  • An eQTL links DNA to RNA, but only in the tissue measured
