# Survey series (5.x): coming soon

Planned classes on the *All of Us* survey data, using the same type 2 diabetes cohort as the other series:

| Class | What it will do |
|---|---|
| **5.1 survey_basics** | How surveys are organised (modules, questions, answers); finding them in the data dictionary and Data Browser; non-answers (*PMI: Skip*, *Prefer not to answer*); skip logic; questions with several answers |
| **5.2 family_history_lifestyle** | Family history of diabetes, smoking, alcohol, physical activity, and type 2 diabetes |
| **5.3 social_factors** | Food insecurity, health care access, and other social factors, and type 2 diabetes |

See `notebooks/CURRICULUM_PLAN.md` for details.
