# Archived notebooks

The original example notebooks, written for the **classic** Researcher Workbench and Controlled Tier Dataset v8. They use Cohort Builder tables (`cb_search_person`, `cb_criteria`), `gsutil`, and the `WORKSPACE_BUCKET` / `WORKSPACE_CDR` variables, none of which exist in Workbench 2.0, so **they won't run as-is**.

They're kept for reference. Use the notebooks in the folder above instead.
